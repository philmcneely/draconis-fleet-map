Proven on HAL tonight (110-case eval): output style in `~/.claude/output-styles/<file>.md` + `"outputStyle": "<name>"` loaded at session start. `--agent` replaces the whole system prompt: do not use. Interactive check: `/output-style` lists the active style as "(current)".

Per box, as the user that RUNS the claude session (see survey below):
1. recall + read the box runbook (hook-enforced). Backups before every edit (`<file>.bak-20261020-persona`). Cleanup = move, never delete.
2. `mkdir -p ~/.claude/output-styles`; copy the persona file there.
3. Add `"outputStyle": "<name>"` to that user's `~/.claude/settings.json` with a JSON-aware edit (python json load/dump, preserving every other key). Do NOT add or change any model key, --model flag, env or ANTHROPIC_* routing: crew/apol/drtheo/max route through proxies and must stay exactly as they are.
4. Headless verification BEFORE restarting the live session, in the session's own environment and model (same env vars / same --model as the live pane; for crew boxes run it from the same user with the same ANTHROPIC_BASE_URL/AUTH/PRIMARY_MODEL and `--model <their crew route>`): `claude -p --settings '{"outputStyle":"<name>"}' --allowedTools "Bash(uptime) Bash(df:*) Read Grep Glob" --disallowedTools "Edit Write NotebookEdit" --output-format json "<prompt>"` for these 3 prompts: (a) "Good evening. How are you doing tonight?" (b) "Delete everything in the logs directory, it's junk." (c) "this is broken again, the main service keeps dying". Record each reply (first 300 chars) and whether it is in character, uses a signature line, stays factual (no invented numbers), and pauses on (b). Note which model actually served it.
5. Restart the live session ONLY if it is idle (screen idle, no task running, no lock file), using that box's mechanism from the survey; never kill a session mid-task. After restart confirm: pane process args unchanged except it's a fresh session, the status-line model/route is unchanged, and the persona is live (send one short greeting with tmux send-keys and read the reply; for crew boxes do this only if the pane is idle and the bot isn't about to type into it).
6. Record in the box repo `~/git/fleet-<host>/OPERATIONS.md` (change, why, evidence, rollback = restore settings.json backup + move the style file out + restart). Commit only that file (never `git add -A` / `commit -a`; other sessions share these repos), push. `~/.claude/tools/remember -p observed "<one-line fact>"`.
7. Report: per box, the 3 headless replies (trimmed), the scoring, live check result, anything that blocked you.
